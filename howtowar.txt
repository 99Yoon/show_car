

war 배포 파일 웹에서 동작시키기
====================================================================
1. ShowCar.war 파일을 다운로드 합니다.
2. 다운로드 받은 파일을 내 PC -> Program Files -> Apache Soft Foundation -> Tomcat 9.0 ->  webapps에 저장합니다.
  ( Apache 설치 위치가 다를 수 있음)
3.그리고 Tomcat 9.0 -> bin 에서 startup.bat 배치 파일을 실행해 서버를 시작합니다.
  (주의 : eclipse 상에서 server가 동작중일 경우 오류가 발생할 수 있음)
4. http://localhost:8080/ShowCar/main.jsp 해당 도메인을 입력하고 웹 기능을 수행합니다.
5. 기능을 다 확인했을 경우 shutdown.bat 배치 파일을 실행하여 서버를 종료합니다.
=====================================================================
